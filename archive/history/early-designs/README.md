## A useful way to read the mistakes

Do not read an old absolute claim as “the author believed this forever.”

Read it as a timestamped state:

```text
claim
  → pushback
  → correction
  → new artifact
  → another reviewer finds another hole
```

That vector is more representative of the project than any one README.
