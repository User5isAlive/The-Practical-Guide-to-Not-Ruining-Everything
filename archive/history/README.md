# Historical Archive

This directory preserves earlier Memory Alpha / Companion Light work as **history, not current authority**.

The point of keeping these artifacts is to make the evolution inspectable: early claims, later corrections, review methods, abandoned ideas, and the conversations that influenced the architecture should remain available without being mistaken for the current specification.

## Reading order

- `../README-Memory-Alpha-v9.md` — the previously archived V9 public README.
- `tranches/2026-09-04/MANIFEST.md` — exact inventory of the old-file tranche supplied on 2026-09-04.
- `tranches/2026-09-04/memory-alpha-history-tranche.tar.gz` — exact-byte source bundle for the tranche's non-PDF files.
- `../research/HUNTER_ENFORCEMENT_SPECIFICATION_v1.0.md.pdf` — HUNTER v9-era specification; the two copies in the 2026-09-04 tranche were byte-identical to this already archived object.

## Rule

Historical material may be cited as evidence of what the project once believed or attempted. It does **not** override the current README, STATUS document, canonical code, or defect ledger.
